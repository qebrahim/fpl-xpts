# fplxpts web

Static frontend for the fplxpts expected-points model: the top ten players in each position by total
expected points over the next five gameweeks. Vite + React 18 + TypeScript, no other runtime dependencies.

## Run

Requires Node 18+ (tested on Node 22.2).

```bash
npm install      # or `npm ci` in CI
npm run dev      # local dev server with hot reload
npm run build    # type-check (tsc --noEmit), then build to dist/
npm run preview  # serve the production build locally
```

`vite.config.ts` sets `base: './'`, so `dist/` works from any sub-path, including a GitHub Pages project
site.

## Data

The page fetches `public/data/projections.json` at runtime (served as `data/projections.json`). The file
is generated by the Python package in the repository root, from the public FPL API, and is copied into
`dist/` unchanged by the build. Its shape is described by the types in `src/types.ts`; the page checks
`schema === 1` and shows an error state for anything it doesn't recognise. If `generated_at` is more than
48 hours old the page shows an "out of date" banner.

Before deploying, set `GITHUB_URL` in `src/config.ts` to the repository URL.
